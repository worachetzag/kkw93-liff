# KKW 93 Reunion — LIFF Web Application

หน้าเว็บลงทะเบียน จองโต๊ะ และสั่งเสื้อแจ็กเก็ต สำหรับงาน **KKW 93 Reunion**
(5 ธันวาคม 2569 เวลา 18.00 น. ณ โรงแรมขอนแก่นโฮเทล)

- แพลตฟอร์ม: LINE LIFF + Google Apps Script + Google Sheets
- ไฟล์นี้เป็น **สำเนาที่ deploy** จากโปรเจกต์หลัก (โฟลเดอร์ `liff/`) — ห้ามแก้ไฟล์ที่นี่โดยตรง

## หมายเหตุ
หน้านี้เป็นส่วนหนึ่งของระบบภายในงาน ไม่ใช่เว็บไซต์สาธารณะ
